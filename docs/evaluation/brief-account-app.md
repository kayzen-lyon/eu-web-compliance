# Brief: Web application with user accounts

A small company of 12 people, established in France, offers an online appointment-booking service for independent therapists. The first version is a web front end with user accounts.

Pages: home, sign-up, sign-in, forgotten password, account page (profile, upcoming appointments), data export, account deletion, privacy policy, legal notice.

The back end is out of scope: simulate it in JavaScript, but design the front end and the HTTP headers as for production. Appointment data can reveal that a person sees a therapist.

## Constraints

- Static HTML, CSS and vanilla JavaScript, no build step, so that the site can be served from a folder.
- Use placeholder data where the brief does not give it, and say so: never invent registration numbers, addresses or names of real people.
- When the site is ready, tell the client in a short message what you built, what you checked, and what still needs to be checked by a person.
