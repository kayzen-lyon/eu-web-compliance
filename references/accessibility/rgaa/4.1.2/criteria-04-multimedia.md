## Criterion 4.1

**Official title:** Chaque [média temporel](glossary.md#media-temporel-type-son-video-et-synchronise) pré-enregistré a-t-il, si nécessaire, une [transcription textuelle](glossary.md#transcription-textuelle-media-temporel) ou une [audiodescription](glossary.md#audiodescription-synchronisee-media-temporel) (hors cas particuliers) ?

### Tests

- **4.1.1** Chaque [média temporel](glossary.md#media-temporel-type-son-video-et-synchronise) pré-enregistré seulement audio, vérifie-t-il, si nécessaire, l’une de ces conditions (hors cas particuliers) ?
  - Il existe une [transcription textuelle](glossary.md#transcription-textuelle-media-temporel) accessible via un [lien ou bouton adjacent](glossary.md#lien-ou-bouton-adjacent) ;
  - Il existe une [transcription textuelle](glossary.md#transcription-textuelle-media-temporel) adjacente clairement identifiable.
- **4.1.2** Chaque [média temporel](glossary.md#media-temporel-type-son-video-et-synchronise) pré-enregistré seulement vidéo vérifie-t-il, si nécessaire, l’une de ces conditions (hors cas particuliers) ?
  - Il existe une [version alternative « audio seulement »](glossary.md#version-alternative-audio-seulement) accessible via un [lien ou bouton adjacent](glossary.md#lien-ou-bouton-adjacent) ;
  - Il existe une [version alternative « audio seulement »](glossary.md#version-alternative-audio-seulement) adjacente clairement identifiable ;
  - Il existe une [transcription textuelle](glossary.md#transcription-textuelle-media-temporel) accessible via un [lien ou bouton adjacent](glossary.md#lien-ou-bouton-adjacent) ;
  - Il existe une [transcription textuelle](glossary.md#transcription-textuelle-media-temporel) adjacente clairement identifiable ;
  - Il existe une [audiodescription](glossary.md#audiodescription-synchronisee-media-temporel) synchronisée ;
  - Il existe une version alternative avec une [audiodescription](glossary.md#audiodescription-synchronisee-media-temporel) synchronisée accessible via un [lien ou bouton adjacent](glossary.md#lien-ou-bouton-adjacent).
- **4.1.3** Chaque [média temporel](glossary.md#media-temporel-type-son-video-et-synchronise) synchronisé pré-enregistré vérifie-t-il, si nécessaire, une de ces conditions (hors cas particuliers) ?
  - Il existe une [transcription textuelle](glossary.md#transcription-textuelle-media-temporel) accessible via un [lien ou bouton adjacent](glossary.md#lien-ou-bouton-adjacent) ;
  - Il existe une [transcription textuelle](glossary.md#transcription-textuelle-media-temporel) adjacente clairement identifiable ;
  - Il existe une [audiodescription](glossary.md#audiodescription-synchronisee-media-temporel) synchronisée ;
  - Il existe une version alternative avec une [audiodescription](glossary.md#audiodescription-synchronisee-media-temporel) synchronisée accessible via un [lien ou bouton adjacent](glossary.md#lien-ou-bouton-adjacent).

### Special cases (cas particuliers)

Il existe une gestion de cas particulier lorsque :

- Le [média temporel](glossary.md#media-temporel-type-son-video-et-synchronise) est utilisé à des fins décoratives (c’est-à-dire qu’il n’apporte aucune information) ;
- Le [média temporel](glossary.md#media-temporel-type-son-video-et-synchronise) est lui-même une alternative à un contenu de la page (une vidéo en langue des signes ou la vocalisation d’un texte, par exemple) ;
- Le [média temporel](glossary.md#media-temporel-type-son-video-et-synchronise) est utilisé pour accéder à une version agrandie ;
- Le [média temporel](glossary.md#media-temporel-type-son-video-et-synchronise) est utilisé comme un [CAPTCHA](glossary.md#captcha) ;
- Le [média temporel](glossary.md#media-temporel-type-son-video-et-synchronise) fait partie d’un test qui deviendrait inutile si la [transcription textuelle](glossary.md#transcription-textuelle-media-temporel), les [sous-titres synchronisés](glossary.md#sous-titres-synchronises-objet-multimedia) ou l’[audiodescription](glossary.md#audiodescription-synchronisee-media-temporel) étaient communiqués ;
- Pour les services de l’État, les collectivités territoriales et leurs établissements : si le [média temporel](glossary.md#media-temporel-type-son-video-et-synchronise) a été publié entre le 23 septembre 2019 et le 23 septembre 2020 sur un site internet, intranet ou extranet créé depuis le 23 septembre 2018, il est exempté de l’obligation d’accessibilité ;
- Pour les personnes de droit privé mentionnées aux 2° à 4° du I de l’article 47 de la loi du 11 février 2005 : si le [média temporel](glossary.md#media-temporel-type-son-video-et-synchronise) a été publié avant le 23 septembre 2020, il est exempté de l’obligation d’accessibilité.

Dans ces situations, le critère est non applicable.

Ce cas particulier s’applique également aux critères 4.2, 4.3, 4.5.

## Criterion 4.10

**Official title:** Chaque son déclenché automatiquement est-il [contrôlable](glossary.md#controle-son-declenche-automatiquement) par l’utilisateur ?

### Tests

### Evaluation mode (provisional, not part of the RGAA)

- **Mode:** `mixed`
- **Code proves:** NC on an `<audio>` or a `<video>` with `autoplay`, not `muted`, with neither `controls` nor a stop button.
- **Remains for a person:** Listen to the page on load: a sound started by a script or a third-party player cannot always be read in the code; a sequence of 3 seconds at most is conforming.

  - Une alternative [compatible avec une API d’accessibilité](glossary.md#compatible-avec-les-technologies-d-assistance) permet d’accéder aux mêmes fonctionnalités.
- **4.13.2** Chaque [média temporel](glossary.md#media-temporel-type-son-video-et-synchronise) et [non temporel](glossary.md#media-non-temporel) qui possède une alternative [compatible avec les technologies d’assistance](glossary.md#compatible-avec-les-technologies-d-assistance), vérifie-t-il une de ces conditions ?
  - L’alternative est adjacente au [média temporel](glossary.md#media-temporel-type-son-video-et-synchronise) ou [non temporel](glossary.md#media-non-temporel) ;
  - L’alternative est accessible via un [lien ou bouton adjacent](glossary.md#lien-ou-bouton-adjacent) ;
  - Un mécanisme permet de remplacer le [média temporel](glossary.md#media-temporel-type-son-video-et-synchronise) ou [non temporel](glossary.md#media-non-temporel) par son alternative.

### Special cases (cas particuliers)

Il existe une gestion de cas particulier lorsque le [média temporel](glossary.md#media-temporel-type-son-video-et-synchronise) ou [non temporel](glossary.md#media-non-temporel) est utilisé à des fins décoratives (c’est-à-dire qu’il n’apporte aucune information).

Dans ces situations, le critère est non applicable.

### Evaluation mode (provisional, not part of the RGAA)

- **Mode:** `mixed`
- **Code proves:** NC on a custom player whose controls have neither an accessible name nor a role (clickable `<div>`, icon alone).
- **Remains for a person:** Check with a screen reader how the media and its controls are conveyed, or that a compatible alternative is present.
