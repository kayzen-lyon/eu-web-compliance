## Criterion 8.2

**Official title:** Pour chaque page web, le code source généré est-il valide selon le [type de document](glossary.md#type-de-document) spécifié ?

### Tests

- **8.2.1** Pour chaque déclaration de [type de document](glossary.md#type-de-document), le code source généré de la page vérifie-t-il ces conditions ?
  - Les balises, attributs et valeurs d’attributs respectent les [règles d’écriture](glossary.md#regles-d-ecriture) ;
  - L’imbrication des balises est conforme ;
  - L’ouverture et la fermeture des balises sont conformes ;
  - Les valeurs d’attribut id sont uniques dans la page ;
  - Les attributs ne sont pas doublés sur un même élément.

### WCAG references listed by the official file

- **Success criteria:** 4.1.1 Parsing (A); 4.1.2 Name, Role, Value (A)
- **Techniques:** H74, H93, H94, F70, F77

### Evaluation mode (provisional, not part of the RGAA)

- **Mode:** `mixed`
- **Code proves:** NC on a duplicate `id`, a forbidden nesting (`<div>` inside a `<p>`, interactive element inside an `<a>` or a `<button>`), a badly closed tag or a duplicated attribute.
- **Remains for a person:** Run the generated source code of the page through the HTML validator.

## Criterion 8.7

**Official title:** Dans chaque page web, chaque [changement de langue](glossary.md#changement-de-langue) est-il indiqué dans le code source (hors cas particuliers) ?

### Tests

- **8.7.1** Dans chaque page web, chaque texte écrit dans une langue différente de la [langue par défaut](glossary.md#langue-par-defaut) vérifie-t-il une de ces conditions (hors cas particuliers) ?
  - L’indication de langue est donnée sur l’élément contenant le texte (attribut `lang` et/ou `xml:lang`) ;
  - L’indication de langue est donnée sur un des éléments parents (attribut `lang` et/ou `xml:lang`)

### Special cases (cas particuliers)

Il y a une gestion de cas particuliers sur le changement de langue pour les cas suivants :

- Nom propre, le critère est non applicable ;
- Nom commun de langue étrangère présent dans le dictionnaire officiel de la langue (voir note 1 ci-dessous) par défaut de la page web, le critère est non applicable ;
- Le terme de langue étrangère soumis, via un [champ de formulaire](glossary.md#champ-de-saisie-de-formulaire) et rappelé dans la page (par exemple comme indication du terme recherché dans le cas d’un moteur de recherche), le critère est non applicable ;
- Passage de texte dont la langue ne peut pas être déterminée : le critère est non applicable ;
- Terme ou passage de texte issus d’une langue morte ou imaginaire pour laquelle il n’existe pas d’interprétation vocale : le critère est non applicable.

Note 1 : le dictionnaire officiel est celui recommandé par l’académie en charge de la langue en question. Pour la France, par exemple, le lien vers le dictionnaire officiel se trouve sur le site de l’Académie française à l’adresse suivante : http://www.academie-francaise.fr/le-dictionnaire/la-9e-edition. Pour toute demande auprès du service du dictionnaire de l’Académie française, utiliser le formulaire de contact du service du dictionnaire.

Note 2 : pour les noms communs de langue étrangère, absents dans le dictionnaire officiel de la langue par défaut de la page web, et qui sont passés dans le langage commun (exemple : newsletter) : le critère est applicable, uniquement lorsque l’absence d’indication de langue peut provoquer une incompréhension pour la restitution.

### WCAG references listed by the official file

- **Success criteria:** 3.1.2 Language of Parts (AA)
- **Techniques:** H58

### Evaluation mode (provisional, not part of the RGAA)

- **Mode:** `mixed`
- **Code proves:** NC on a passage written in the code in a language other than that of the page, without a `lang` attribute.
- **Remains for a person:** Spot the foreign-language passages of dynamic or translated content, which cannot be read in the template.
